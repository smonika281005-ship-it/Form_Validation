Contact Form with JavaScript Validation

## Overview
This project is part of my **Web Development Internship (Task 6)**.  
The objective was to create a **Contact Form** with client-side validation using **JavaScript**.

The form validates:
- **Name** → must not be empty  
- **Email** → must follow a valid email format (checked with regex)  
- **Message** → must not be empty  

On successful validation, a **success message** is displayed.

## Tools Used
- **HTML5** → for form structure  
- **CSS3** → for styling and user-friendly design  
- **JavaScript** → for input validation and dynamic feedback  
- **VS Code** → development environment  
- **Chrome Browser** → testing  

---

## Features
- Real-time **error messages** under each input field  
- **Regex-based email validation**  
- Prevents form submission if inputs are invalid  
- Displays a **success message** when all inputs are valid  
- Automatically **resets the form** after successful submission
